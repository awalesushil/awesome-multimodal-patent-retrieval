## Surveys

- [A Survey on Patent Analysis: From NLP to Multimodal AI](https://doi.org/10.18653/v1/2025.acl-long.419) (ACL 2025) - Survey of patent analysis tasks, from text-based methods to multimodal approaches.

## Patent Image Retrieval

- [Intermediate Domain Alignment and Morphology Analogy for Patent-Product Image Retrieval](https://papers.nips.cc/paper_files/paper/2025/hash/154743e7e9688cf77db5ee75807bda82-Abstract-Conference.html) (NeurIPS 2025) - Retrieves patent drawings for product photos by bridging the domain gap between the two.
- [Hierarchical Multi-Positive Contrastive Learning for Patent Image Retrieval](https://ceur-ws.org/Vol-4062/paper7.pdf) (PatentSemTech 2025) - Contrastive learning with several positives per query for patent drawing retrieval.
- [Large Language Model Informed Patent Image Retrieval](https://ceur-ws.org/Vol-3775/paper11.pdf) (PatentSemTech 2024) - Uses LLM-derived text knowledge to improve patent image retrieval.
- [DeepPatent: Large scale patent drawing recognition and retrieval](https://doi.org/10.1109/WACV51458.2022.00063) (WACV 2022) - Large-scale dataset and baselines for patent drawing recognition and retrieval.
- [Learning Spatial Relationships between Samples of Patent Image Shapes](https://openaccess.thecvf.com/content_CVPRW_2020/html/w8/Castorena_Learning_Spatial_Relationships_Between_Samples_of_Patent_Image_Shapes_CVPRW_2020_paper.html) (CVPR Workshops 2020) - Learns shape representations of patent drawings for similarity search.

## Multimodal Prior-Art Search

- [Integration of Images into the Patent Retrieval Process](https://doi.org/10.1007/978-3-030-15719-7_49) (ECIR 2019) - Doctoral work on combining patent images with text in the retrieval process.

## Patent Figure Classification and Understanding

- [Patent Figure Classification Using Large Vision-Language Models](https://doi.org/10.1007/978-3-031-88711-6_2) (ECIR 2025) - Evaluates large vision-language models for classifying patent figure types and perspectives.
- [Classification of Visualization Types and Perspectives in Patents](https://doi.org/10.1007/978-3-031-43849-3_16) (TPDL 2023) - Dataset and models for classifying the visualization type and viewing perspective of patent figures.
- [PatFig: Generating Short and Long Captions for Patent Figures](https://doi.org/10.1109/ICCVW60793.2023.00305) (ICCV Workshops 2023) - Dataset and models for generating short and long captions of patent figures.
- [Automatic Generation of Explanatory Text from Flowchart Images in Patents](https://ceur-ws.org/Vol-3604/paper4.pdf) (PatentSemTech 2023) - Generates explanatory text from flowchart figures in patents.
- [Flowchart recognition for non-textual information retrieval in patent search](https://doi.org/10.1007/s10791-013-9234-3) (Information Retrieval Journal 2014) - Recognises the structure of flowchart drawings to make them searchable.
- [Classifying Patent Images](https://ceur-ws.org/Vol-1177/CLEF2011wn-CLEF-IP-MorzingerEt2011.pdf) (CLEF-IP 2011) - Patent image type classification for the CLEF-IP 2011 task.

## Vision-Language Models for Patents

- [DesignCLIP: Multimodal Learning with CLIP for Design Patent Understanding](https://doi.org/10.18653/v1/2025.findings-emnlp.553) (Findings of EMNLP 2025) - Adapts CLIP to design patents for classification and retrieval.

## Datasets and Benchmarks

- [IMPACT: A Large-scale Integrated Multimodal Patent Analysis and Creation Dataset for Design Patents](https://papers.nips.cc/paper_files/paper/2024/hash/e3301977b92f28e32639ec99eb08f4a1-Abstract-Datasets_and_Benchmarks_Track.html) (NeurIPS Datasets and Benchmarks 2024) - Large multimodal dataset of design patents with images and text.
- [PDTW150K: A Dataset for Patent Drawing Retrieval](https://doi.org/10.1007/978-3-031-56435-2_5) (MMM 2024) - Dataset of about 150K patent drawings for drawing retrieval.

## Tools and Demos

- [Exploring Patents Visually: An Interactive Search System for Multimodal Patent Image Search and Interpretation](https://ceur-ws.org/Vol-4062/paper8.pdf) (PatentSemTech 2025) - Interactive system for searching patent images with text and image queries and interpreting the results.
